# 따공 발표 대본

예상 50~60초. 문장이 끝날 때 다음 화면으로 넘어갑니다.

| 시간 | 화면 | 발표 멘트 |
| --- | --- | --- |
| 00:00–00:13 | 홈의 우산 이야기 카드를 엽니다. | 비 오는 날, 우산을 기울여 준 이웃이 오래 기억나죠. 따공은 대가 없이 건넨 작은 도움과 고마움을 동네 이야기로 남기는 서비스예요. |
| 00:13–00:25 | 우산 이야기의 예시 대표 댓글을 보여 줍니다. | “저도 비 오는 날 우산을 조금 기울여 볼게요.” 시연 속 댓글이에요. 누군가의 도움을 알아보고, 다른 사람도 해 볼 계기가 되면 좋겠어요. |
| 00:25–00:42 | 로컬 승인 화면의 `+1P`와 홈의 노란 행정구역 지도를 차례로 보여 줍니다. | 승인된 이야기 한 편이 해당 지역에 온기 한 점을 더해요. 지도는 최근 일주일 점수를 인구 십만 명당으로 환산해 개나리색의 밝기로 보여 줘요. |
| 00:42–00:58 | LP 카드 한 장과 추천 이유를 보여 준 뒤 따공 이름을 띄웁니다. | 응원은 노래로도 전할 수 있어요. 관심 지역 글을 일주일 안에 다시 읽는지, 작은 도움으로 이어지는지 살펴볼게요. 혼자 뿌듯함을 느끼지 말고 나누세요~ |

화면에는 `1P`를 표시하고 음성에서는 ‘한 점’으로 읽습니다. 지도는 앱에 등록된 이야기의 게시 활동을 나타냅니다. 첫 파일럿은 7일 내 같은 지역 재열람, 도움 연결을 추가한 후에는 당사자가 확인한 요청 완료를 측정합니다.
