# 해커톤 개발 기록

따공은 2026년 11월 27일 **Codex Community Hackathon – Seoul**의 개발 시간인 **14:00–16:30 KST, 2시간 30분** 동안 만들었습니다. 코드 작성과 수정에 Codex를 사용했고, 여덟 세션이 사용자 관점의 반론부터 구현, 발표 준비, 독립 검증까지 병렬로 진행했습니다. [행사 안내](https://luma.com/p8l79x8m)

## 여덟 세션이 맡은 일

| 세션 | 맡은 일 | 다음 작업에 전달한 내용 |
| --- | --- | --- |
| A | 사용자 관점의 반론과 회귀 검사 | 읽기 전용 안내, 차단과 실패, 지역 낙인 등 우려가 실제 화면에서 어떻게 드러나는지와 재현 조건 |
| B | 반론에 대한 조사와 검증 | 공식 자료와 합성 예문의 대조 결과, 비판과 연대의 경계, 인구 보정과 글 심사의 해석 범위 |
| C | 모바일 UI와 접근성 | 홈 소식 카드, 다섯 탭, 작성과 심사 상태, 지역 탐색 및 키보드 동작 |
| D | 지역 데이터와 온기 계산 | 행정경계와 인구 출처, 한국 시간 기준 7일 집계와 인구 보정 검사 |
| E | 기획과 개발 문서 | 화면에서 할 수 있는 일, 로컬 실행과 배포 방식, 사용자 검증 지표 |
| F | 시연 영상과 제출 문구 | 촬영 순서, 발표 대본, 자막과 소개 문구, 영상 길이 검사 |
| G | 앱 기반과 통합 준비 | 데이터 계약, 로컬 Codex 심사 연결, 빌드·테스트와 통합 후보 |
| H | 독립 감사 | 구현 담당자의 보고와 별도로 재현한 결과 및 수정이 필요한 항목 |

조정 세션은 사용자 결정과 공통 타입을 공유하고, 검증한 변경을 `main`에 통합했습니다. Vercel 배포와 iPhone 시뮬레이터 촬영도 조정 세션이 맡았습니다.

## 변경을 공유하고 다시 검토한 방법

1. **작업 트리를 나눴습니다.** 각 구현 세션은 Git worktree에서 자기 영역을 수정했습니다. 화면, 지역 계산, 상태와 심사 연결은 공통 타입을 기준으로 합쳤습니다. 다른 영역에 영향이 있는 변경은 해당 담당자에게 먼저 알렸습니다.
2. **공유 문서에 쓰기 잠금을 사용했습니다.** 문서마다 작성 담당자를 두고, 같은 파일을 두 프로세스가 고치는 경우 `flock`으로 쓰기를 순서대로 진행했습니다. 별도 두 프로세스에서 한쪽이 잠금 해제까지 기다리는 동작을 확인했습니다.
3. **요청과 결과를 이벤트로 전달했습니다.** 반론, 답변, 검토 요청, 빌드 완료는 수신 역할을 정해 공유 수신함에 발행했습니다. 브로커는 이벤트가 완성된 뒤 공유 폴더에 원자적으로 게시했습니다. 수신 세션은 확인(`ack`)과 처리 결과(`done`)를 기록했습니다. 웹훅으로 받은 요청도 같은 수신함에 들어갔으며, 완료된 턴이 새로 열리고 수신 기록이 남는 것을 확인했습니다.
4. **새 작업이나 정기 점검 때 세션을 다시 호출했습니다.** 브로커는 진행 중인 턴에는 새 요청을 전달하고, 턴이 끝난 세션에는 새 턴을 시작했습니다. 마지막 수신함 확인 이후 590초가 지나면 점검을 요청했습니다. 여덟 역할에서 새 이벤트 없이 정기 점검으로 다시 호출된 기록을 확인했습니다.

예를 들어 A가 일곱 번째 대화 응답 뒤 초점이 문서 본문으로 이동하는 문제를 재현했습니다. 통합본에서는 입력창이 닫힐 때 응답 완료 안내로 초점을 이동하도록 고쳤습니다. A가 같은 시나리오를 다시 실행했고, H는 iPhone 검증 기록을 대조했습니다.

## 행사 시연에서 확인한 것

- 동일한 릴리스의 타입 검사·빌드와 자동 테스트 12개를 통과했습니다. 독립 검토에서는 로그인 없이 내려받은 Vercel 파일 14개의 SHA-256을 빌드 결과와 대조했습니다.
- iPhone 17 Pro 시뮬레이터의 Safari에서 16개 지역을 열고, 최신·인기 전환과 프로필·배지·노래 추천·예시 대화를 확인했습니다. 화면 크기와 입력 방식에 따른 차이를 살피기 위해 Chrome에서도 좁은 폭, 확대, 키보드 이동과 지도 라벨 간격을 확인했습니다.
- 로컬 시연에서 합성 문장으로 실제 Codex 승인과 차단을 실행했습니다. 승인한 이야기 한 편은 서울의 점수를 3P에서 4P로 올렸습니다. 차단된 글은 초안이 남았고 해당 지역 점수는 그대로였습니다. Vercel 공개 시연에서는 예시 콘텐츠를 읽을 수 있었으며 게시 심사 경로는 404를 반환했습니다.
- 같은 버전의 iPhone 화면을 직접 녹화해 한국어 음성과 자막을 넣은 85초 소개 영상을 제작했습니다.
